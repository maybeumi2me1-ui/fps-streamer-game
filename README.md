# FPS 主播模拟器 V0.4

**FPS 排位 × 主播经营** 的 7 天文字经营 H5 游戏，使用 Vue 3 + TypeScript + Vite，在现有项目上升级。无需账号、后端或 API 密钥。

🎮 游戏：https://maybeumi2me1-ui.github.io/fps-streamer-game/

## 玩法

每天：**开播准备 → 选择直播风格 → 5 个排位关键节点 → 每回合直播互动 → 下播结算 → 主播成长**。

- 直播风格：技术型（胜率 +5%，节目系数 0.8）、娱乐型（胜率 -4%，节目系数 1.35）、均衡型（初始团队 +1）。每日开播后固定，第二天可以改。
- 手枪局、经济局、中盘局、关键残局、决胜局各有 2～3 个选择，先做竞技决策，再完成一次直播互动。
- 每个关键节点代表普通回合的一个片段：拿下时比分 +3:1，失利时 +1:3。第五个节点后依据全部五次结果换算为 13 分胜负，不是真实逐回合 FPS。
- 胜率综合枪法、精力、装备、队伍士气、战术、比分压力、段位难度和观众挑战，并在按钮中直接展示。可选的三次点击预瞄每次 +1%，没有强制操作或倒计时超时惩罚。
- 稳健通常更容易赢；冒险胜率低但节目效果更高；ECO 换弱装备攒资源；全起花钱换强装备；保枪放弃当前关键节点，保存装备和资源。
- 经济上限 4，初始 3。手枪局稳健/配合花费 1，冒险花费 2；之后回合胜利补充 1，失利补充 2。装备会延续，失利通常降一档，保枪保留当前装备。
- 每天可以练枪一次（枪法 +6 / 精力 -20）、剪辑预热一次（下场曝光 +20 / 精力 -15）、休息一次（精力 +25）。设备最多升级三次，每次花费 `150 × 新升级级别`，提升收入与关注转化。

## 观众、挑战与切片

- 8 位有固定昵称和性格的常驻观众，96 条原创基础弹幕，另有比分、战术、连胜败、粉丝、人气、历史事件和挑战状态的动态内容。
- 弹幕以 1.8～3.6 秒间隔逐条出现；只保留最近 12 条，后台页面暂停弹幕。关注与礼物通知随回合结果产生，挂机不会刷奖励。
- 5 种挑战：手枪限定、激进突破、禁用步枪、禁止 ECO、独狼。每场首次互动可接受其中一个；从**下一关键节点**开始持续两个节点，改变装备、可选战术和胜率。必须两次都赢才得节目 +18 和礼物 ¥12。可中途放弃，不得奖励。
- 30 个条件事件：战术 10、残局 5、队友 5、挑战 5、经营 5。按阶段、段位、粉丝、比分、预算和之前的选择筛选；优先避免同场/近期重复。只有没有其他符合条件的互动时才允许复用通用事件。
- 每日仅保留质量最高的一条技术型、娱乐型或教学型切片。免费发布增加 `round(质量 × 0.4)` 关注（最多 45），次日曝光为 `round(质量 × 0.8)`；花费 ¥80 可推广一次，次日曝光再 +25。总曝光上限 120，下场结算后消耗。
- 每场自然新增关注上限 240、收入上限 ¥180、礼物累计上限 ¥90；排位胜利最多 +48 分，失利通常 -12～19 分。输了比赛仍能通过表现、节目和切片获得成长。切片的即时收益单独计入新增关注。
- 广告只预留 `AdService` 接口，**没有真实广告、支付或广告收益**。广告不可用不影响免费发布、金币推广与通关。

## 本地运行与构建

需要 Node.js 20.19+ 或 22.12+（验证使用 24.19.0）。

```sh
npm ci
npm run dev
```

在开发机浏览器中打开终端显示的地址。生产 Pages 构建及本地预览：

```sh
npm run build -- --mode github-pages
npm run preview -- --mode github-pages
```

Pages 模式的访问路径为 `/fps-streamer-game/`；默认构建使用相对路径，支持其他静态托管。GitHub Pages 是静态站点，游戏运行不请求外部素材或服务。

## 测试

```sh
npm test
npm run build -- --mode github-pages
npx playwright install chromium
npm run test:browser
```

有系统 Chromium 时自动使用 `/usr/bin/chromium`；也可以通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定。无系统浏览器时使用 Playwright 安装的 Chromium。浏览器测试会自行启动和关闭 4180 端口的生产预览；使用 `BASE_URL` 可以测试已运行的页面（该地址需提供本版本游戏）。

- 逻辑测试：战术结果、经济、全部 5 种挑战、延迟奖励、防重复结算、30 个事件可达性、3 种切片、收益上限、三种风格的 7 天模拟、旧档迁移和直播/结算续档。
- 浏览器测试：7 天 / 35 个关键节点及互动、逐条弹幕、观众挑战、预瞄、每回合刷新续档、防重复选择、切片传播、广告降级、重新开始、损坏存档恢复、桌面和 390px 手机布局、Pages 子路径资源加载。
- 浏览器截图输出至已忽略的 `artifacts/`。

## 存档与代码结构

继续使用当前浏览器的 `localStorage` 键 `fps-streamer-save-v1`，内部版本升级为 4。旧版粉丝、资产、枪法、精力、设备、日期和历史记录会迁移；旧版没有保存的比赛细节不会被伪造。V0.4 每次行动、回合、互动及弹幕更新后保存，直播中刷新恢复当前阶段与随机状态；已结算的选择不能再次领取奖励。

存档只在同一浏览器、同一站点下有效，不跨设备同步。清理浏览器数据会删除进度；重新开始需要确认。存储被浏览器禁用时会提示，仍可在当前页面继续游玩。

| 文件                          | 职责                                       |
| ----------------------------- | ------------------------------------------ |
| `src/game/types.ts`           | 比赛、主播、切片与存档类型                 |
| `src/game/content.ts`         | 30 个事件、5 个挑战、选项与数值配置        |
| `src/game/engine.ts`          | 状态转移、胜率、经济、结算与奖励上限       |
| `src/game/chat.ts`            | 常驻观众、96 条弹幕、条件语境              |
| `src/game/storage.ts`         | 校验、迁移与自动存档                       |
| `src/game/ads.ts`             | 尚未接入广告的服务接口                     |
| `src/components/FpsScene.vue` | 原创 SVG 港区、HUD、枪械与反馈             |
| `src/App.vue`                 | 原有桌面布局上的准备、直播、结算、数据中心 |

画面为原创 SVG/CSS 的战术港区，包括建筑、管线、电缆、货柜、门窗、透视地面、阴影、手枪/步枪与轻量反馈；不含《无畏契约》素材、第三方图片、真实 3D FPS、多人联网或真实直播服务。

## GitHub Pages

推送 `main` 后现有 `.github/workflows/deploy-pages.yml` 自动执行锁定安装、逻辑测试、TypeScript/Pages 构建及 7 天浏览器检查，全部通过后才部署 `dist/`。

已开启 Pages 的仓库无需改设置。若需要首次启用：仓库 **Settings → Pages → Build and deployment → Source → GitHub Actions**。

在仓库 **Actions → Deploy game to GitHub Pages → 最新运行** 查看 `build` 和 `deploy`，两者绿色表示发布完成。失败时点击失败步骤看错误；修复后 **Re-run all jobs**。也可 **Run workflow → main → Run workflow** 手动触发。
